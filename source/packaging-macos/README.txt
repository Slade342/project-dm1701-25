Project DM1701-25 for macOS

Drag Project-DM1701-25.app to Applications and double-click it.

The first launch needs Python 3.10 or newer with Tk. The official macOS
installer from python.org includes Tk. The app then creates its private runtime
under ~/Library/Application Support/Project-DM1701-25 and installs the Python
packages there. Your codeplug files remain yours; uninstalling the app does not
delete them.

The bundled firmware image is experimental P25 Phase 1 receive-only firmware.
RF reception, first boot, and speaker output still require physical-radio
validation. Back up before flashing.
