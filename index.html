Project DM1701‑25

A standalone CPS for the Baofeng DM‑1701 / Retevis RT84: FM, DMR, and an experimental P25 Phase 1 receive workflow.

Install the application

Use the single offline setup file. It creates Project DM1701-25 on your desktop and opens the CPS directly—no folder of runners to click. Python and the required packages are included, so installation does not need to download anything.

macOS app

Download the single app bundle, unzip it, and drag Project-DM1701-25.app to Applications. The first launch creates its private runtime automatically and opens the CPS directly—no terminal command or folder runner. macOS needs Python 3.10+ with Tk (the official python.org installer includes it).

macOS first launch: this development bundle is not code-signed or notarized. If Gatekeeper blocks it, Control-click the app, choose Open, then confirm. The experimental P25 image and radio-risk warning below apply to both platforms.
P25 status: the package includes a real experimental flashable receiver image with P25 FEC/IMBE and speaker output linked. RF capture, first boot, real-time timing, and speaker output are not validated on a physical radio, so reception is not guaranteed. The image is RX-only.
